# Data-sharing statement

**Study:** Measurement-day ambient temperature, blood pressure and blood glucose in India's National Family
Health Survey (NFHS-5, 2019–21): a cross-sectional analysis.

## What is publicly shared (this repository)

| Item | Content |
|---|---|
| Complete analysis code | ERA5-Land download, data preparation, exposure linkage, all models, bootstrap, spatial analysis and figures (`code/`) |
| Results | the scripts print every estimate to the console and write plain CSV result files and basic plots, so that each reported estimate can be reproduced and checked |
| Data dictionary | definitions of every derived variable (`docs/DATA_DICTIONARY.md`) |
| Synthetic test data generator | `tests/make_synthetic_data.R`, which builds a fake dataset with the same file and variable names so that the whole pipeline can be run and checked without DHS access |

## What cannot be shared, and why

| Item | Reason | How others can obtain it |
|---|---|---|
| NFHS-5 microdata (IAPR7EFL) | DHS Program terms of use prohibit redistribution | Free registration and project approval at https://dhsprogram.com |
| NFHS-5 GPS coordinates (IAGE7AFL) | Restricted geographic data; DHS terms prohibit redistribution | Requested with the survey data from the DHS Program |
| Person-level analytic files (`output_full/*.rds`, `output_revision/analysis_dataset_v2.rds`) | Derived from DHS microdata | Regenerated by the scripts from the DHS files |
| Cluster-level linked exposures (cluster × date temperature, displacement simulation) | Linked to cluster IDs, these would reveal approximate (≈10 km) cluster locations, i.e. derived GPS information | Regenerated by `nfhs5_temperature_full_period.R` and `02b_extra_exposures.R` |
| District boundaries | DHS Spatial Data Repository licence | https://spatialdata.dhsprogram.com |

ERA5-Land data are freely available from the Copernicus Climate Data Store (https://cds.climate.copernicus.eu)
under the Copernicus licence; the scripts download exactly the variables, area and period used.

Any registered DHS user can reproduce every result by running the scripts in the order given in `README.md`.
